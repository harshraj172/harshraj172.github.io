Instructions

For each example E1–E40, open the source, find the failure, and pick three labels. Please do this independently, without discussing with other annotators, and without an LLM choosing the labels (say in the notes if you used one to read a long trace).

  1. Edge: the two components the root failure happened between.
  2. Fault side: which of the two is responsible, so where the fix belongs.
  3. Failure mode: the mode listed for that edge. Definitions are under “Taxonomy”.

Rule. Find the earliest failure the run does not recover from, and the edge it happens on. Blame the model if the other side behaved as specified and the model could have avoided or recovered from it. Otherwise blame the side that actually failed.

If the source can’t support a confident answer, tick “Insufficient evidence” and still give your best guess. Add a confidence from 1 to 5.

Progress saves in this browser. When done, click Export JSON and send the file to Harsh.
